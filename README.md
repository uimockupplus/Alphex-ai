## About

Alphex AI builds AI-powered products and solutions that help people and
businesses put artificial intelligence to work. Our focus is on making
AI systems useful, grounded, and accessible---not just experimental
demonstrations.

Our approach is guided by four principles:

-   **Reliable by design** --- build solutions with dependable behaviour
    in mind.
-   **Grounded in your data** --- connect AI experiences to relevant
    information and context.
-   **Human handoff when needed** --- keep people involved when a task
    requires judgement or intervention.
-   **Built for real work** --- prioritize practical outcomes and
    usability.

## Products

### EvalLoop

EvalLoop is part of the Alphex AI ecosystem. It focuses on structured
evaluation of AI-generated responses, helping assess dimensions such as
factuality, relevance, instruction following, completeness, safety, and
overall quality.

### EvalLoop Jobs

EvalLoop Jobs is an opportunity-discovery directory focused on AI and
related work, including AI/LLM evaluation, data annotation, AI training,
and other emerging AI opportunities. It helps people discover
opportunities; it is not an employer or recruitment agency.

> Product availability and features may evolve as Alphex AI develops.

## Local Development

1.  Clone this repository:

    ``` bash
    git clone <repository-url>
    ```

2.  Move into the project directory:

    ``` bash
    cd <repository-directory>
    ```

3.  Open the project using your preferred code editor.

4.  Follow the setup requirements for the current implementation. If
    environment variables are required, create a local `.env` file using
    the variable names expected by the application.

Because the project setup can change, use the repository's actual
configuration files as the source of truth for install and run commands.

## Deployment

The website is deployed using Vercel.

For deployment:

1.  Connect the GitHub repository to Vercel.
2.  Configure the required build settings for the project.
3.  Add the required environment variables in the Vercel project
    settings.
4.  Deploy the project.
5.  Connect the appropriate domain and verify the deployment.

Never commit API keys, access tokens, database credentials, or other
secrets to GitHub.
